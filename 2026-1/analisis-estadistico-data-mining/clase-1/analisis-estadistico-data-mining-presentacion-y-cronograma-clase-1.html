1 Idea central

El curso une estadística y minería de datos para convertir datos (elementos aislados sin valor propio) en información útil que permite tomar decisiones.

4 Lo esencial de la clase

Metodología del curso

  • Clases remotas síncronas por videoconferencia.
  • Materiales con grabaciones, teoría, evaluaciones y guías.
  • Participación activa: se puede interrumpir para consultar.
  • Herramientas: R (estadística) y Python (minería).
  • Entornos: RStudio, VS Code o Google Colab.

Cronograma de temas

  • Descriptiva: tendencia central, dispersión e histogramas.
  • Inferencial: hipótesis, intervalos y representatividad.
  • Data Mining: limpieza obligatoria antes del modelado.
  • Algoritmos: K-means (clustering), árboles (clasificación) y asociación.
  • Ética: privacidad y confidencialidad de datos sensibles.

Proyecto final (desde semana 13)

  • Identificar un problema real.
  • Recopilar y limpiar un dataset (con data sintética de investigación).
  • Implementar modelos estadísticos y de minería.
  • Presentación final que prioriza funcionalidad y sustento técnico.

E

Ejemplos prácticos

Caso 1 — Retail: analizar los datos de ventas de una tienda para identificar patrones de compra ayuda a optimizar el inventario; con K-means se segmentan clientes en grupos similares para marketing personalizado.

Caso 2 — Investigación de mercados: estudiantes usan Python para limpiar datos de encuestas y aplican estadística descriptiva (media, mediana, histogramas) para resumir los resultados.

✓ Qué recordar

  • El dato aislado no tiene valor: se convierte en información al analizarlo.
  • R para estadística; Python para procesamiento y minería de datos.
  • El proyecto final arranca en la semana 13 con data sintética.
  • Cada práctica pesa 15%; la Evaluación Integral, 40%.

Idea central de la sesión: el curso completo sigue un solo hilo: describir los datos, generalizar desde muestras, mineri­ar patrones y aplicar todo en un prototipo con ética de por medio.
